关联证据：`work/coh_rot_findings.md`、`work/floor_verification_notes.md`、`work/error_decomposition_notes.md`

## 0. 机制假设与预测

**H1**：LEADER 的旋转误差（MOE）中存在约 **1.3° 的"地板"**（t→0 时 r 收敛不到 0，跨四个测试序列稳定 1.249–1.377°，占 MOE ≈ 82%），它由**坐标误差场的相干旋转分量**承载，而非误差大小（每点 ‖ĉ−c‖）。

- TRR 只惩罚每点误差大小 ‖ĉ_i − c_i‖，**不约束误差场的旋转结构**；
- 局部实测：误差场旋转分量与最终旋转误差的相关系数 **+0.598**（误差大小为 +0.352）；**只消平移分量对 r 无效（0.0%）**，**只消旋转分量即拿到全部收益**。

**H1 的可检验预测**：在训练目标中显式约束该分量 → MOE 下降（**尤其低 MPE 子集**），MPE 基本不退化；而"同量级但无机制含义的随机旋转约束"不产生同等收益。

## 1. 三个臂（最终版本）

| 臂 | 损失 |
|---|---|
| **A** | `L = L_TRR` |
| **B** | `L = L_TRR + λ · L_coh-rot`，`L_coh-rot = d(R_e, I)` |
| **C** | `L = L_TRR + λ · L_random-rot`，`L_random-rot = d(R_e, R_rand)` |

其中 `(R_e, t_e) = argmin_{R,t} Σ_i w_i ‖R ĉ_i + t − c_i^GT‖²`（加权 Kabsch/SVD），`R_e` **不是车辆 pose**，而是"预测坐标场整体还需再旋转多少才能与 GT 场对齐"。

### ⚠️ C 臂的硬约束（两次修正记录）

- **错误写法 1（已废弃）**：`d(R_rand, I)` —— 与模型预测无关，是常数，**梯度为零**，不构成对照。
- **错误写法 2（同样废弃）**：`d(R_e, R_rand)` 且 `R_rand` 为**零均值各向同性**随机旋转。在旋转群上 `min_{R_e} E_R[d(R_e,R)]` 的解**仍是 `R_e = I`**（恒等是旋转群的"中心"），故该损失与 B 的期望梯度**同向**，C 会跟着一起变好 → **对照失效**。零均值随机目标不能用来做这个对照。
- **正确写法（本版本，二选一，必须写明用的是哪个）**：

  **C-i 固定非恒等目标**：`L = d(R_e, R_ref)`，`R_ref` 每帧相同且**非恒等、非零均值** —— 例如绕车体 z 轴 +θ_ref（符号固定），`θ_ref` 按训练初期 `mean|R_e|` 校准，使 C 与 B 的损失值和梯度范数同量级。
  → 它回答的正是："**梯度结构相同、目标不同**，结果是否不同？" 预期 C 不变差已属不易，绝不应出现 B 那样的改善。

  **C-ii 打乱目标的估计**：把"应被压掉的真实方向"换成"由**打乱对应**估出的方向"：
  - 线性 ω 版本：`L = ‖ω̂_shuf‖²`（`ω̂_shuf` 由打乱后的对应关系拟合得到）；
  - Kabsch 版本：`L = d(R_e, R_e^shuf)`，`R_e^shuf = Kabsch(pred, shuffle(tgt))`（注意打乱后角度可达 100°+，必须按 §5 截断/缩放，否则量级不可比）。
  → 它回答："只有当**目标方向**有物理含义时才有收益。"

- **量级与对照有效性的检查**：C 臂必须对预测产生**真实且与 B 同量级**的旋转梯度。训练日志中记录 B/C 的梯度范数与损失值，**若偏离超过 2×，则判定该对照失效**（在报告中如实标注，不得据此宣称机制成立）。
- **C 要回答的问题**：**"只是多加一个同量纲的旋转梯度，就会变好吗？"** 只有 B 好、C 不好，才能支持"相干旋转这个具体目标有价值"，而不是"随便加个旋转正则都行"。

## 2. 数据划分与 λ 选择

- **训练**：现有训练序列。
- **内部选模（内部验证）**：从训练序列中划出，**λ 只在这里选**。
- **开发集（已接触）**：96 帧点级缓存 / 617 帧区域 —— **只能用于诊断，不得用于挑 λ 或挑 checkpoint**（已接触数据不得当盲测，见总表 F.9）。
- **测试**：全量 104,735 帧口径（未被训练）。

**λ 扫描**：λ ∈ {0.1, 0.3, 1.0} → 1(A) + 3(B) + 3(C) = **7 个训练配置**。
成本考虑：若资源紧张，可先跑 A + B(λ=0.3) + C(λ=0.3) 三配置做机制判定，再补 λ 扫描；但**不得**用开发集来补选 λ。

## 3. 评估口径（关键：固定子集）

**主口径（必须报告）**：冻结 **A 臂（TRR baseline）中 MPE ≤ 5 cm 的帧列表 F₀**，然后对 A/B/C 各臂报告**同一批 F₀ 帧**上的 MOE。
- 理由：若各臂按自己的 MPE ≤ 5 cm 重新筛帧，B 可能只是改变了**哪些帧进入集合**（组成效应），而非真的把地板打下来。
- 这条才真正回答："**同一批本来平移已经很准的帧，旋转地板有没有被打下来**。"
- **F₀ 必须在 A 臂训练完成后立即导出并冻结**（保存帧索引列表及其哈希，写入报告），后续任何臂都不得重新计算 F₀。阈值 5 cm 与"用哪个臂的 MPE 定义"一并冻结。

**补充口径（描述性，不作为判据）**：各臂自己的 MPE ≤ 5 cm 子集 MOE。

**常规口径**：全量 MPE/MOE、分序列（4 个测试序列）、失败率（t>1m 或 r>2°）、`|R_e|`/`|ω̂|` 的分布、逐帧改善比例、bootstrap CI。

## 4. 预注册判据

### 支持 H1（成功）需同时满足
1. B 的**全量 MOE** 相对 A 改善 **≥ 3%**，且 bootstrap 95% CI 不含零；
2. B 在**固定子集 F₀** 上的 MOE 改善 **≥ 5%**（机制靶点）；
3. B 的 **MPE 退化 ≤ 1%**（不得以牺牲平移换取旋转）；
4. **C 的对应改善 < B 的一半**，或 C 的 CI 含零（随机旋转目标无效）；
5. **方向一致性**：≥ 3/4 测试序列同向。

### 判负 / 不确定
- B 的全量 MOE 改善 **< 1%** → H1 判负（训练侧旋转项不是有效杠杆）；
- B 改善 ≥ 3% 但 **C 也有同等改善** → "只是多加了正则/旋转监督本身"，**不能**支持"相干旋转结构有其特殊价值"，需重新设计对照；
- B 在 F₀ 上改善但 C 也改善且量级相当 → 同上；
- B 的 MPE 退化 > 3% → 该配置不可接受（即使 MOE 下降）。

### 附：机制层面的辅助判据（不作为成败门槛）
- B 训练过程中 `|R_e|` 的分布应整体左移（尤其是中位数）；
- B 与 C 的 `|R_e|` 轨迹应出现分离（B 下降、C 不下降或上升）。

## 5. 实现约束（来自本轮实测）

| 约束 | 依据 |
|---|---|
| **鲁棒化必不可少** | 96 帧中 **3/96（3.1%）** 的帧 Kabsch 崩溃（`|R_e|` 最大 **179.32°**），且有崩溃帧的原始误差并不大（r=1.449°，非难帧）。不加处理会让 93 帧的 −41% 变成 +510%。做法：Huber 化、按 `|R_e|` 截断（>20–30° 视为无效）、或残差加权 Kabsch。 |
| **点集要够大且加权** | top-50%（n≈456）时 `|R_e|` 的抽样标准差约 ±2°，与信号（~0.8–1.4°）同量级。低可靠度点每点误差是高可靠点的 **7.46×**（2.224 m vs 0.298 m），不可等权。建议全点 + 可靠度加权。 |
| **量纲归一化** | TRR 单位是米，`d(R_e, I)` 是弧度；λ 意义取决于归一化方式，必须在文档中写明（例如 `λ·L_coh-rot / 1rad`）。 |
| **日志** | 每步记录：损失各项、梯度范数（B vs C）、`|R_e|` 的分位数、低 MPE 子集的 r。 |

**参考上界**（oracle，非训练可达）：96 帧上"把 R_e 归零后重解"给 **−41.4%**（排除 3 个崩溃帧，93 帧，80.6% 帧改善）；线性 ω 版本给 −20.9%（全部帧）。实际训练收益预期远低于上界（R_e 与最终误差相关系数仅 +0.424/+0.598）。

## 6. 与既有结论的关系（写结论时必须核对）

- 本实验属于**训练侧**，与已判负的推理侧手段（选点/加权/精修/门控/阈值/后处理融合）不冲突：那些都在处理"误差大小"，本实验打的是"误差结构"。
- 不得与多模态路线混比口径（多模态基线用纯 LEADER，交付指标仍以 v1 full_refine 0.25293/1.58386 为准）。
- 若本实验判负，则"训练侧旋转项"这一敞口方向也应记入判负清单，并注明原因（H1 被否证 vs 实现不可行）。
- **本实验与"多模态能否救"不是两个并列方向，而是同一个机制假设（相干旋转分量是 MOE 主体）的验证路径**；多模态的可行性上界（+4.5pp，热点区）已被单独量过。
