# 跨帧对比监督的锚定残差融合

分支 `research/anchored-contrastive-fusion`，基于跨帧视觉消歧探针的必要条件阳性结果，单独验证这些区分信息能否转化为冻结 LEADER 回归头可利用的特征。不延续通道调制和收益门控。

模块是无参数 LayerNorm 输入、640→32→512 的两层 MLP，共 37,408 个参数。末层零初始化，残差范数限制为原 LiDAR 特征范数的 5%。原 top-K 中最高可靠的一半及无图像点残差恒为零；原编码器、MMRegressor、DeDoDe 和 PCA 全部冻结。

使用原 TRR 加 0.01 倍跨帧多正例对比损失，温度 0.1。相似度作用于归一化后的融合 512D 查询和冻结原 LiDAR 参考；回归仍读取未归一化的融合特征。对比损失为正例指数和与所有明确正负例指数和之比的负对数。0.5 m 内为正例、2 m 外为负例、中间距离忽略；同帧及近重复排除规则沿用探针。固定原 LiDAR 16 候选，不以 GT 插入正例，不筛掉原本排序正确的可调整训练点。

905 帧统一缓存分为 578 帧训练、145 帧内部选模和 182 帧已接触开发评估。训练与所有机制评估均使用同一个仅来自 578 帧的参考库，因此开发机制候选与上一轮 723 帧参考库有所不同，会重新报告原 LiDAR 排序基线。内部／开发参考不进入训练库。

正确与帧内置乱视觉各三个种子（2089、2090、2091），每组满 100 epoch、batch 8 帧，AdamW、权重衰减 1e-4、前 5 epoch 预热至 1e-3，余弦下降到 1e-5。只按 145 帧内部平均最终位置误差选择 0、10、…、100 轮中的检查点，平局取早者；不挑最好种子、不重新拟合、不解冻回归头。零初始化可获选，但即使如此每组仍训练满 100 轮并保存末轮权重。

最终在新 182 帧上重算纯 LEADER、历史①，并比较六个选定模型的标准定位、固定原候选定位和固定 LiDAR 候选的描述子排序。记录原 Matcher 候选／保护集合与歧义点的交集、保护点最终保留率。历史①使用旧已训练权重，仅为历史参考，不能认为与本轮训练数据和预算相同。

轨迹块不确定性规则在开发姿态结果生成前固定：每日期按时间排序，超过 10 秒断开，每块最多 10 帧；日期内重采样轨迹块 10,000 次，种子271828，对三个种子的逐帧均值作配对差值。开发集已用于消歧探针，不是盲测。

复现环境为 WSL egonn118。依次运行：

```bash
python check.py
python experiment.py --stage prepare
python experiment.py --stage train
python experiment.py --stage evaluate
python report.py
```
