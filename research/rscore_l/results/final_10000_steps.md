# R-SCoRe-L：10,000 步局部实验最终结果

训练 907 张、验证 303 张、开发测试 148 张。全部预定队列已完成，包括三个训练日期交叉训练、可靠性头训练及最终验证/测试推理。下列主模型为单帧几何监督、LiDAR 共视图、两级坐标回归和可靠性头；多帧作为独立对照，没有另行训练多帧可靠性头。

## 主结果：148 张测试图

成功要求平移误差 <1m 且旋转误差 <2°。

| 方法 | 视觉平均误差 m / ° | 视觉中位误差 m / ° | 视觉成功数 | 融合成功数 |
|---|---:|---:|---:|---:|
| GLACE | 1.790 / 5.653 | 0.857 / 3.018 | 23 / 148 | 115 / 148 |
| R-SCoRe-L，无可靠性头 | 0.963 / 5.177 | 0.542 / 2.117 | 55 / 148 | 111 / 148 |
| R-SCoRe-L，含可靠性头 | 0.963 / 5.177 | 0.542 / 2.117 | 55 / 148 | 117 / 148 |
| 原 LEADER 缓存 | — | — | — | 117 / 148 |

R-SCoRe-L 相比 GLACE 的平均视觉平移误差降低约 46%，视觉成功数增加 32 帧。但两者不是相同总计算预算：R-SCoRe 使用 10 个检索假设，GLACE 缓存只有一个假设；原生关键点数量也不同，完整 JSON 另含每假设 256 点的指标。

## 融合结果的含义

可靠性头不改变坐标回归或当前 PnP，因此独立视觉定位与无可靠性头版本相同。加入可靠性头后，仅 3 / 148 帧接受视觉修正，145 帧保持原 LEADER 位姿，挽救 0 帧、损害 0 帧。成功数恢复到 117，不能解释为超越原 LEADER。

原 LEADER 平均误差为 0.170924m / 1.555090°；含可靠性头为 0.171155m / 1.553666°，整体基本持平。无可靠性头接受 103 帧，损害 6 帧；GLACE 接受 73 帧，挽救 1 帧、损害 3 帧。

## 消融与多帧

| 方法 | 视觉平均误差 m / ° | 视觉成功数 | 融合成功数 |
|---|---:|---:|---:|
| 原版 R-SCoRe | 5.837 / 5.709 | 4 | 117 |
| 原版深度初始化 | 2.274 / 5.130 | 26 | 114 |
| 持续几何监督、原图 | 14.277 / 17.432 | 12 | 117 |
| 持续几何监督、LiDAR 图 | 0.963 / 5.177 | 55 | 111 |
| 多帧几何监督、LiDAR 图 | 1.186 / 5.389 | 57 | 112 |

在当前配置下，LiDAR 共视图对应的实验臂带来最明显的视觉改善，单独加入持续几何监督没有改善结果。多帧将实际训练缓存覆盖率从 2.80% 提高到 3.52%，验证集稍有改善，但测试平均误差变差，不能认定为稳定提升。各臂只使用一个训练随机种子，不能据此得出普遍因果结论。

## 可靠性与限制

- 三个交叉训练模型均完成 10,000 次迭代，可靠性样本 85,480 个，其中训练 48,720、校准 36,760；验证和测试未用于拟合。
- 校准 ECE 为 0.0976、Brier 为 0.0967，高置信度区间仍存在明显过度自信，不能称为校准问题已经解决。
- 缺少训练侧真实 LEADER 候选池，候选排序损失没有实际训练；因此已完成的是当前可运行版本，不是附件全部监督目标。
- 几何标签是经过筛选的弱表面参考，缺少独立标定和静态真值核验。
- 本地预算为 10,000 次迭代，并非官方四卡 100,000 步预设；混合精度可能跳过少量更新。
- 测试集曾用于开发，融合使用原局部实验的 v1_two_stage 候选缓存，没有重跑 main 的完整 LiDAR 前端。

## 推理耗时

RTX 4060 Laptop 8GB 上，16 张测试图加一次预热的测量：视觉前端约 0.295 秒/帧，缓存 LEADER 输入上的融合约 0.056 秒/帧，合计约 0.351 秒/帧；独立视觉 PnP 另需约 1.043 秒/帧。峰值显存约 6,186MB。上述时间不包含 LiDAR 前端计算和模型加载，不能当作完整系统端到端耗时。

当前结论：视觉前端有局部改善证据，系统融合尚未证明增益；暂不据此替换 main 默认方法。
