# 交叉消融结果解读

本轮没有证据表明换成 DINOv2 或扩大到 5×5 邻域能稳定改善定位。以下是同一64训练/32开发帧、六相机、600步、三配对种子、相同two-stage后端的均值。

| 方法 | MPE m | MOE ° | 三个种子各32帧成功数 <1m/2° |
|---|---:|---:|---|
| 原始 LEADER | 0.089917 | 0.902717 | 31/31/31 |
| 同预算纯 LiDAR 微调 | 0.116364 | 0.936320 | 31/31/31 |
| DeDoDe＋中心 Query | 0.115823 | 0.932871 | 32/31/32 |
| DeDoDe＋5×5 Query | 0.113907 | 0.936630 | 31/31/31 |
| DINOv2＋中心 Query | 0.116136 | 0.937704 | 32/31/31 |
| DINOv2＋5×5 Query | 0.117170 | 0.939028 | 31/31/31 |

## 两个因素各自的影响

- DeDoDe 中加入邻域：平均 MPE 减少1.92mm，MOE 增加0.00376°；平移在两个种子变差、一个种子改善，不能称为稳定提升。
- DINOv2 中加入邻域：平均 MPE 增加1.03mm，MOE 增加0.00132°；没有显示邻域优势。
- 中心 Query 换成 DINOv2：平均 MPE 增加0.31mm，MOE 增加0.00483°。
- 邻域 Query 换成 DINOv2：平均 MPE 增加3.26mm，MOE 增加0.00240°。

这些差异很小，未进行支持统计显著性的独立测试。不能据此泛化为 DeDoDe 一定强于 DINOv2，也不能证明图像特征没有价值。当前结果仅针对本次融合结构、128D PCA、训练预算和开发帧。

四个视觉模型移除图像后的平均 MPE 全部更低；DeDoDe邻域、DINOv2中心和DINOv2邻域移除图像后，MPE/MOE均值都更低。打乱图像后也没有稳定退化，因此尚未证明当前模型有效利用了正确的视觉对应。下一步应优先诊断融合监督与微调方式，而不是仅扩大邻域或替换骨干。

## 为什么之前单种子 DINOv2 表格看起来更好

本轮 seed2089 的 DINOv2邻域仍为0.085122m/0.933661°，平移比原始LEADER好、旋转更差；但三个种子平均为0.117170m/0.939028°。单种子表格的平移优势不能等同于跨种子稳定收益。之前单Cam5邻域实现、输入尺寸及PCA拟合范围也不同，本轮不是对旧模型的逐项完全复刻。

## 控制检查与限制

四个视觉组均391,685个优化参数；同一初始化、同一帧顺序及voxel采样、相同训练时图像丢弃。原始LEADER历史基线逐帧误差精确复现，最大差异0。五项模型检查及96帧特征审计通过。

两骨干使用相同448×616图像、相同像素位置与14像素邻域间隔；128D PCA都只用相同20,056个训练可见中心点拟合。DeDoDe保留98.49%方差，DINOv2保留87.50%，因此结论包含骨干与PCA压缩的共同影响，不能单独归因于语义能力。

四组均覆盖44,299/67,710个voxel，中心与邻域组覆盖完全一致；由于统一输入分辨率改变了栅格化可见性，这不是旧六相机缓存的45,133个voxel，但不影响本轮四组内部的覆盖控制。

初次提取遭遇宿主C盘写满，发生于训练前。56个完整新缓存无损压缩且逐数组一致性通过，13个不完整新缓存移除后重新提取，最终96帧均通过审计。原始数据未删除。Windows扫描文件启用了无损NTFS压缩；临时WSL内存/交换限制已恢复原配置并验证备份哈希相同。未重启正在承载其他任务的WSL。
