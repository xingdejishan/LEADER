# 端到端基准（2026-10-24）

使用 `gpu_sparse`，96 个固定输入，来自之前的 48 帧普通池与 48 帧压力池。同一组输入分别运行单帧、单卡四流、三卡六分片。原始扫描和同步 RGB 均实时读取，SAM 使用既有预处理缓存，LEADER/V7、几何和视觉候选均实时运行，输出最终 T；未读取 GT。

## 结果

| 模式 | GPU | 含初始化墙钟 | 96 帧处理区间 | 全处理区间/输出数 | 剔除各片首 4 帧后的短样本吞吐 |
|---|---|---:|---:|---:|---:|
| 单帧 | 3 | 114.52 s | 95.39 s | 993.63 ms/帧 | 886.51 ms/帧，1.13 FPS |
| 四流批处理 | 3 | 104.76 s | 86.12 s | 897.10 ms/帧 | 761.27 ms/帧，1.31 FPS |
| 六分片，每片四流 | 3/4/5，每卡两片 | 43.78 s | 26.68 s | 277.93 ms/帧 | 202.01 ms/帧，4.95 FPS |

“毫秒/帧”吞吐不是单帧延迟。单帧和四流各剔除前 4 帧，保留 92 帧；六分片每片剔除 4 帧，共保留 72 帧。六分片后续处理区间只有 14.54 s，没有全局预热屏障；不能视作全集长期稳态或单卡成绩。

单帧服务耗时（读入/准备 + 完整计算，排除预取排队）：平均 **974.61 ms**，P50 894.56 ms，P95 **2036.01 ms**，最大 2766.96 ms。

按实际预取队列从输入读取开始到整批 T 可交付的延迟：

| 模式 | 平均 | P95 |
|---|---:|---:|
| 单帧 | 1768.89 ms | 2784.56 ms |
| 四流批处理 | 6416.61 ms | 8969.50 ms |
| 六分片 | 10725.84 ms | 15795.17 ms |

批量入口等整批计算完成才交付 T，预取的下一批可能等待上一批计算，故该延迟可能远大于聚合平均输出间隔。单帧服务值是在现有预取运行条件下拆出的服务时间，不是关闭其他预取后的完全隔离实测。

模型初始化单帧模式 12.52 s，四流 13.51 s，六分片各进程约 12.88 s；含初始化墙钟另包含入口校验、输入摘要、进程启动和轮询退出等开销。

## 瓶颈

单帧剔除前四帧后的平均阶段工作耗时：

| 阶段 | 平均 |
|---|---:|
| SAM 缓存读取与样本准备 | 78.49 ms |
| LEADER | 263.21 ms |
| V7 refine | 222.00 ms |
| 几何专家 | 169.32 ms |
| 视觉候选生成 | 178.36 ms |
| GPU 选择/仲裁 | 51.22 ms |

这些阶段工作量不是六分片吞吐时间，不能直接逐列相加后与六分片平均输出间隔比较。选择模块在单帧模式 P95 89.59 ms，六分片 P95 95.64 ms，但完整链路仍未达到 100 ms/帧。

## 输出与安全核对

三个模式每组均输出 96 帧：92 帧 success，4 帧因没有视觉候选回退并标记 degraded，无 error。单帧、四流和六分片的 T0、最终 T、分支选择在这 96 帧全部一致，没有重新做精度或全集评估。

仅使用事先空闲的 GPU 3/4/5，不触及其他 GPU 上的任务；每个进程 PyTorch 显存上限 15%，六分片实测单进程分配峰值最多约 1.50 GB，不包含全部 CUDA 驱动开销。保留主机 RAM、GPU 空闲显存与超时保护，只清理本次创建的进程组。未更改虚拟环境或安装依赖。

## 复现与产物

`benchmark_e2e.py` 为有限启动器，`e2e_profile_worker.py` 仅包装计时，不改变算法。计时在最终 CUDA 同步后结束，不含随后 JSONL 落盘；覆盖输入读入、样本准备、缓存读入和各计算阶段。启动器保存计时包装器摘要；每份输出的 meta 保存模型、输入和算法源码摘要。

```bash
/home/zhangcy/.conda/envs/leader/bin/python -B benchmark_e2e.py \
  --keys-file results/e2e_benchmark_keys96_20261024.json \
  --gpus 3,4,5 --timeout 800
```

全部原始输出、日志及汇总：`results/e2e-bench-20261024-1792818231070933121/`，主文件 `summary.json`。本地汇总副本为 `online_parallel_work/e2e_benchmark_summary_20261024.json`。
