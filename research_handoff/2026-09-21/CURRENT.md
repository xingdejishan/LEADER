# 当前状态（唯一现行口径）

## 基线和路径

共同初值A：冻结LEADER预测缓存 → SC2-PCR `Matcher.estimator` → `full_pool_refine`（阈值1.2、0.6的两阶段）→中心还原。不是IRLS B0，也不是仅SC2-PCR。源码与具体参数已随快照固定。

| 标识 | 实际路径 |
|---|---|
| A | 上述基线直接输出 |
| G | 从A开始，同精修器只使用LiDAR几何残差 |
| C | 从A开始，按像素的图像残差与几何项联合求解 |
| D | 从A开始，整块Huber视觉因子；sqrt(64)=8尺度修复已包含 |
| U | D加初值处固定的平面不确定性传播矩阵 |
| W | D因子乘训练侧确定的0.92745056，整体减弱对照 |

D/U/W的Huber尺度0.41133925来自64训练帧；外层仍为soft_l1。C与D只在小残差二次区域作尺度对齐，不能称所有残差范围的目标等价。默认不计算可见性诊断，mask仍参与有效性检查。

[原始诊断](evidence/current/surface_geometry_uncertainty_leaveout_20260921.json)及[哈希记录](evidence/current/surface_geometry_uncertainty_diagnostic_20260921_hashes.json)：source口径10个有效平面样本，projection_xyz口径164个；两者95%覆盖率均0，观测变化大于当前模型预测。方向诊断15个有效配对，衰减中位0.99057867，7/15低于0.99；这不证明衰减方向就是有害位姿牵引。

几何差分无效方向只在2/32帧出现，各帧patch无效率中位仍为0；无效方向不能据此解释主要收益。U有7帧xtol退出，最大optimality55.70，success不能直接解释为充分收敛。
