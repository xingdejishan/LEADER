## 3. 问题结构与检索过程

首先将问题写成：已有较准的状态估计，但一个高维、可能有偏且与先验纠缠的测量生成器，不能稳定产生有益的状态修正。

检索从以下结构出发，而非先指定网络架构：

1. 小初始误差下，从连续图像证据恢复低维几何状态：image registration、direct alignment、feature-metric localization。
2. 多个测量共同受偏差影响，以及判别式后验和观测似然的区别：correlated biased measurements、discriminative Bayesian filtering、likelihood ratios。
3. 具有三维模型和二维传感图像、训练数据很少的逆问题：medical 2D/3D registration、differentiable rendering。
4. 错误状态也能形成高分的感知歧义：perceptual aliasing、active perception、hypothesis disambiguation。

不进入候选的检索结果：

- DiffPose 的“用物理前向模型产生候选状态下的图像”具有启发，但 X-ray 衰减成像模型和患者专属 CT 渲染不能直接套到 RGB；缺少可用外观渲染器时，仅引用它不构成可执行机制。

## 4. 最多三个迁移候选

### 候选一：连续特征度量对齐（论文迁移，保留但不选择）

1. **原领域问题：** PixLoc 在给定三维模型和粗位姿后，用特征对齐恢复六自由度位姿，而不是从头回归绝对姿态。
2. **同构结构：** 我们同样已经有较好的 LEADER 初值；需要的是围绕初值的真实视觉误差梯度。
3. **最小原语：** 对每个 T 重新采样 `F_query(project(T,X))`，与地图参考特征形成残差；其 Jacobian 是图像特征梯度乘投影 Jacobian。官方 [costs.py](https://raw.githubusercontent.com/cvg/pixloc/master/pixloc/pixlib/geometry/costs.py) 直接实现了这一链条。
4. **输入与独立性前提：** 地图点、合法参考图像、当前 query 图像、标定及几何初值；参考特征不能由当前查询 GT 或当前候选输出生成。需要在目标域具有局部可辨识性的特征。迁移此原语可以使用现有冻结特征；不把下载新的外部权重默认为已授权。
5. **错误候选能否利用：** 能。重复结构和弱辨识特征也会形成低残差；连续优化只能更准确地优化既有目标，不能使错误目标变正确。
6. **与负结果关系：** 相比 C，观测随 T 重新取样；但如果仍使用已证明峰值错误的 raw cosine，其与 V3 的证据不足问题高度重叠。仅替换求解器不够。
7. **在线动作：** 改变视觉目标函数和每次迭代的采样位置，输出连续位姿更新。未选原因是现有特征域上的负证据较强，且可能再次把“更好求解器”误当成“更好测量”。

### 候选二：由三维表面约束的真实图像块对齐（论文迁移，唯一选择）

1. **原领域问题：** FAST-LIVO2 用 LiDAR 建立几何表面，将真实参考图像块附着到地图点，用图像对齐改善状态估计。
2. **同构结构：** 几何已经提供接近正确的位姿、深度和表面结构；视觉应提供细粒度外观位置约束，而不是重新承担大范围匹配。
3. **最小原语：** 用地图表面法向和深度将参考图像块的各像素绑定到三维表面，再按当前候选位姿投影到 query 图像，比较真实图像采样。官方 [vio.cpp](https://raw.githubusercontent.com/hku-mars/FAST-LIVO2/main/src/vio.cpp) 包含表面法向驱动的 homography/affine warp。
4. **输入与独立性前提：** 固定地图局部几何、参考图像及其建图位姿、当前图像、内外参、T_L。局部表面近似合理，同一表面在两图中可见，标定与同步足够准确。参考模板来自地图侧，不能从 query 裁出来再与自己匹配；重复使用的图像块不能被假设成无限多个独立测量。只迁移测量原语，不移植其 IMU、连续轨迹状态或在线地图更新。
5. **错误候选能否利用：** 能。周期纹理、镜面、动态物体、错误法向、遮挡和时间偏差都可支持错误位姿。三维 warp 增加物理约束，并不是正确性证书。
6. **与负结果关系：** V2/V3 未使用这种表面约束的像素足迹；XRefine 读局部图像块但不使用地图法向、深度和全帧共享物理 warp；C 使用冻结上下文预测候选分数。因此这是不同的测量生成机制，而不是修补原有分数。
7. **在线动作：** 改变采样的真实 query 像素及视觉残差，直接驱动唯一位姿更新。选择它是因为不需要用 47 帧再训练网络，且精确针对目前未显式使用的局部表面形变。代价是更依赖外观稳定性和地图/标定质量。

不能搬用 FAST-LIVO2 的整机精度、延迟或鲁棒性承诺：原系统是带惯导与时间连续性的里程计，我们是单次地图重定位。论文还报告法向精修在某些数据上没有稳定收益，因此当前冻结法向，不加入在线法向优化。

### 候选三：只融合相对于几何条件的视觉似然增量（实验驱动假设，借鉴相邻领域；不进入本轮）

1. **原领域问题：** DKF 处理神经解码等高维测量到低维状态的推断：学到的 `p(state|measurement)` 不是 `p(measurement|state)`，融合时需要处理其训练先验。
2. **同构结构：** V2 和 C 都把 LiDAR 条件输入视觉头，而后端又使用 LiDAR 先验；D 说明几何条件本身能产生非平坦预测。把这种预测直接叫“纯视觉似然”没有依据。
3. **最小原语：** 若能获得同一训练分布下、校准且有共同支持的条件密度，则 `p(T|I,L)/p(T|L)` 与 `p(I|T,L)` 成比例。新增结构是“几何条件基准密度＋视觉条件密度”之间的似然增量，而不是任意加权两个已有分数。
4. **输入与独立性前提：** 仍是原有 L、I；训练侧必须估计真实条件分布及其采样先验，测试前冻结。这里不要求无条件 I 与 L 独立，但需要一致的条件概率语义及支持集，不能把不确定性很大的 density ratio 当精确证据。
5. **错误候选能否利用：** 能。分母过小或分布外区域会把错误候选无限放大；低几何概率不等于高视觉证据。
6. **与负结果关系：** 由 C/D 矛盾提出，但当前 C/D 按位姿损失训练，softmax 并未被证明是校准条件后验，且二者共享 RoMa 选择的观测。直接相除既不满足推导，也可能只是重新加权失败分数。因此不能拿现有 checkpoint 做 ratio 小修补。
7. **在线动作：** 合格时会改变融合目标中的视觉似然项；当前没有满足前提的概率模型，故不安排实现或试验。

此候选是针对本项目的原创机制假设，不是原创 Bayes 公式，也不宣称已构成论文创新；暂不具备本轮实验准入条件。

## 5. 唯一选择的机制推导

### 5.1 必须先明确“观测”是什么

记查询点云为 L，图像为 I，地图为 M，LEADER 位姿为 T_L=f(L,M)。我们的目标是用 I 对 T_L 增加约束。

`u_L=project(T_L,X)` 是预测，不能作为新的视觉测量。由 `g(I,u_L)` 输出的像素也不自动成为独立测量；它依赖初始几何，误差模型必须承认这种依赖。

当前选择直接写一个生成式外观约束：若候选位姿正确，同一三维表面在参考图像与 query 图像中的纹理经过几何形变及亮度归一化后应一致。此处真正观测是图像采样值；投影是观测函数，二者角色清楚。

### 5.2 从一个点改成一小块物理表面

对地图点 X_i，在其参考相机坐标系内拟合冻结局部平面：

`n_i^T X = d_i`。

参考图像块内像素 s_ij 的射线为 `v_ij = K_r^-1 [s_ij,1]^T`，射线与平面的交点为：

`X_ij^r = d_i v_ij / (n_i^T v_ij)`。

再用固定建图位姿转换到世界坐标 X_ij。必须保留 observation-specific 的实际 world_xyz 和 reference_pixels；同一个 0.2 m voxel ID 不代表同一个物理点。

由此同一个 patch 的邻域像素不再被当成“中心周围可自由滑动的一块方形图”，而是附着在一组固定三维表面点上。

### 5.3 用同一个位姿解释所有图像块

以下约定 T 是世界到查询机体的变换，π_c 包含第 c 个相机的固定外参和内参，更新为 `T(δ)=Exp(δ^) T_L`。实现时必须把 LiDAR 协方差转换到这一相同扰动约定，不能直接混用已有 body-to-world 参数化。

当前位姿下的 query 图像块为：

`q_i(δ) = [I_q,c(π_c(T(δ) X_ij))]_j`。

固定参考块为 `r_i=[I_r(s_ij)]_j`。定义去均值并归一化的向量 N(v)，视觉残差为：

`e_i(δ)=N(q_i(δ))-N(r_i)`。

这相当于使用局部归一化相关的直接残差，消除简单的增益和偏置变化；不宣称能消除阴影、非线性响应或跨季节外观变化。归一化的数值下限由图像量化尺度固定，弱纹理不会凭空提供几何信息。

每一个 δ 都重新决定图像采样位置。上一轮最小实现只让旋转增量 δ_R 参与优化；本轮保留这一条作为 B 路径，并增加由同一表面 patch 观测和冻结 LiDAR 证据共同约束的六维 C 路径。两者的纹理空间导数都通过投影 Jacobian 传递到对应状态：

`∂e_i/∂δ = J_N · ∇I_q · J_projection · J_pose`。

这条导数链是实际动作：图像告诉优化器哪个方向能使同一表面的投影更贴合，而不是让网络根据原始匹配状态猜一个 offset。

### 5.4 只计入一次几何约束

采用统一目标：

`E(δ) = 1/2 δ^T Λ_L δ + Σ_g (1/|S_g|) Σ_{i∈S_g} ρ(||e_i(δ)||² / σ_V²)`。

Λ_L 从冻结 LEADER 的几何支持计算，σ_V 从地图侧/训练侧的参考图像残差估计并冻结；不在开发集扫描融合权重。g 为固定的参考图像–相机观测块，归一化限制重复 patch 的数量优势，不把该目标包装成完全独立、精确校准的后验。

只使用这一份 LiDAR 局部先验，不再叠加同源几何残差，也不把最终投影生成的 correspondence 再送回后端当“另一份视觉证据”。这是近似局部 MAP 型目标，不承诺 Λ_L 是真实定位误差的精确协方差。

法向、地图点、参考位姿和标定保持冻结；仅优化 δ。若这些量有系统误差，它们可以偏置最终位姿，此机制没有自动校准能力。

在线支持由初始几何可见性、已有相机 mask 和地图表面有效性确定，不能读取 GT visibility。优化中不能通过把高残差点移出画面、删掉困难 patch 或改变分母来降低代价；使用固定支持，离开有效采样域的步长按同一优化域规则处理。

所有帧使用相同目标和求解流程：B 输出 `T_out=Exp(δ_R*^) T_L`，C 输出 `T_out=Exp(δ*^) T_L` 并开放平移。两条路径都不比较新旧位姿后逐帧挑选，不使用 baseline fallback。零增量可以是统一目标的驻点，但空支持、超时或数值异常必须单独记失败，不能伪装成成功保留基线。

### 5.5 原创性与失败假设的准确定位

本轮可否证命题是：在现有图像、地图和 LEADER 初值上，显式绑定三维表面的真实 patch 观测，能否在不恶化 MPE 的前提下降低 MOE。

历史数据支持提出这个问题，但尚未证明“缺少表面 warp”是当前失败根因。引入它的理由是有一条具体、未被现有代码实现的观测链，以及来自同构问题的正式证据。

这个最小版本属于有依据的方法迁移，不称为新的 SOTA 或原创论文方法。即便测试通过，也只说明该观测结构在本开发协议中有用，不能直接把 FAST-LIVO2 的原语据为原创。

## 6. 当前唯一最小测试

### 固定范围

- 数据采用既有 96 帧清单中的完整 32 帧开发 split；地图和参考图像仅来自原 64 帧 map/train split。
- 这些数据已经参与过去分析，只能标开发集；不把它称作独立测试。
- 本机制不需要现有 RoMa 匹配缓存，因此不以“只有 8 帧缓存”为理由缩减开发分母。
- 冻结 LEADER、输入点云、地图、参考图像、内外参、mask 和 seed。重放或读取经过 parity 的无 GT 初值；A 与新方法使用逐帧相同 T_L。
- 本轮只运行 A、B、C：A 为冻结 LEADER，B 为修正采样和求解后的 rotation-only，C 为同样测量下的 LiDAR 约束六维联合更新。每条路径均输出唯一最终位姿。不新训练网络，不尝试多个特征模型，不展开额外消融矩阵或另一条方法路线。

### 最小实现含义

只实现参考 patch 的三维表面绑定、参考/查询图像浮点双线性重采样、固定几何先验下的连续旋转更新和 LiDAR 约束六维联合更新。B、C 使用同一批 patch 和图像设置；不增加 null 分类器、置信度网络、法向精修、曝光预测网络或学习型接受器。

参考实现的 8×8 patch 与每层最多 5 次更新可作为固定工程起点；它们来自官方配置而非 GT 调参。图像金字塔尺度、几何邻域拟合、数值容差与 σ_V 的地图侧估计规则在运行开发集前一次性写入协议并 hash，不开展参数扫表。本文件确定机制和判定，不把尚未执行的数据尺度估计伪装成已经冻结的数值。

### 判定

必要的开发准入条件同时成立：

1. 同一完整分母上，新方法的 MPE 不高于 A 且 MOE 低于 A；不使用两者加权和掩盖其中一项变差。
2. 平移与旋转 P90 均不恶化；报告全部逐帧改善、退化和原阈值下的 rescue/damage。
3. 无跳过帧、无 GT 派生选择、无逐帧回退；空支持与运行失败保留在分母及失败数中，不能只报告成功样本均值。
4. 同时报告原始输入至最终输出的总耗时和新增部分耗时；冻结缓存的测量单独标记为重放，不能写成在线总延迟。

单纯视觉目标下降、图像看起来更齐、平均像素误差下降或输出接近 LEADER 都不算通过。32 帧同序列开发结果不能证明跨日期泛化或统计独立的显著收益。

如果任一位姿指标继续恶化，停止当前“固定地图表面 patch 直接精修”的具体分支；不立即增加网络、候选、gate 或扫描损失权重。失败只否证这一协议下的具体迁移，不否证全部视觉信息和所有直接法。
