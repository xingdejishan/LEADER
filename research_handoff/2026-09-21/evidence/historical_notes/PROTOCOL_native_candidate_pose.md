# 原生视觉候选与最终位姿监督：开发实验

本实验实现 A/B/C/D 最终位姿对照。现有缓存有 47 帧训练数据、8 帧开发数据，全部属于 2012-02-18；不得将结果称为按采集序列隔离的独立测试。根据用户指示，缺少所需条件的独立序列测试本轮暂不运行。

## 固定协议

- A：冻结 LEADER，沿用原始帧序号对应的 `2089 + frame_index` 随机种子和 full-pool 输出。
- B：现有 RoMa 对应加受保护后端，固定 `sigma_t=0.1 m`、`sigma_r=1°`、`visual_lambda=1`、`floor=1 px`、留出观测接受比率 `0.95`；不按开发集重新选择配置。
- C：冻结 RoMa precise，提取最后一次正向 stride-1 原生精修层 `warp_head` 之前的 32 维上下文表示，同时使用其原生像素预测、精度矩阵、重叠概率；小型 MLP 为 LiDAR 投影附近 13×13 原始像素位置及无匹配类别生成概率。
- D：与 C 同一网络、初始化、训练帧、训练顺序及训练预算，将全部 36 维视觉输入置零并重新训练。几何输入、候选可见性和 LiDAR 约束相同。

每帧全部点通过共享位姿假设聚合候选概率：固定零修正及 128 对反对称 Sobol 假设，平移范数不超过 0.15 m、旋转不超过 1.5°；每个假设使用精确多相机投影，通过双线性采样获取候选概率，逐相机平均后加入 LiDAR Hessian 相关结构与固定尺度先验，得到可微后验与共享 `Δξ`。

这是离散位姿假设上的可微求解近似，**不是连续 Gauss–Newton 优化器**。监督使用更新后位姿的真实平移范数和 SO(3) 测地旋转误差：`translation / 0.1 m + rotation / 1°`。训练不读取逐点 GT 像素，不依据查询 GT 可见性筛选对应，也不以像素精度作为位姿实验的门槛。无有效候选时返回 LEADER 位姿。

训练固定 40 epochs、AdamW、学习率 0.001、随机种子 2089；不使用开发集选 epoch 或选模型。训练结束后对 8 帧开发数据评估一次，保留每帧修正、A/B/C/D 误差及 checkpoint。

## 解释范围

1. C/D 使用相同的既有 RoMa 筛选观测集合，D 仍继承观测选择中的视觉信息；D 检验的是输入视觉证据的增益，不是完全独立于图像的地图点选择基线。
2. 候选精修表示来自 RoMa 原生上下文层，不再仅用独立描述子余弦相似度。
3. 报告 MPE、MOE、平移与旋转 P90、各项和任一项退化比例；退化相对于同帧 A，容差为 `1e-8`。
4. 分别记录原生前端重放、重新计算位姿假设投影、新位姿头耗时；原始观测选择与缓存 I/O 未计入。D 的位姿头耗时不代表完整无图像系统的耗时，B 的前端耗时用相同 RoMa 重放测量值近似。
5. 独立测试成功标准保持原要求：C 同时优于 A、B、D 的 MPE/MOE；本轮开发集无论改善与否都不能证明达到该标准。

## 运行

在安装了 RoMa、PyTorch 和 SciPy 的环境运行：

```sh
python research/prevoxel_multiview/visual_pose_candidates.py build
python research/prevoxel_multiview/visual_pose_candidates.py train
```

默认沿用本机 WSL 数据位置；可用参数覆盖 manifest、LiDAR、匹配缓存、输出目录和设备。缓存逐帧保存并校验 manifest 与原始匹配缓存的 SHA-256，不覆盖旧实验结果。
