# 位姿条件外观 + 可见性判据实验（不训练、不加传感器）

数据：290 帧难题子集里筛出 **208 帧**，每帧 8 个既有候选（`out/disc2/` 的 P20 通道，未重跑匹配）。
正确=误差 <5 m，错位=7–12 m。共 **962 对**（其中 926 对在两种位姿下都有 ≥50 个共同投影点）。
日期分布：2012-02-12 175 帧/714 对，2012-02-19 23/162，2012-03-31 4/14，2012-05-26 5/36。

## 1 样本与投影规模

| 项 | 值 |
|---|---|
| 样本帧 / 候选 / 候选对 | 208 / 1664 候选（8.0 每帧）/ 962 对（共同支撑 926） |
| 每帧参考帧数（中位数） | 5（冻结的 TOP_K_REFERENCES，取自 P20 检索表前 5） |
| 每候选中位投影点数 / 覆盖 patch 数 | 70 336 个点 / 610（1200 个 DINOv2 patch 的 51%） |
| 历史点落在画面内的比例（中位数） | 0.66 |
| 查询帧自身 LiDAR 点数（中位数） | 24 408 |

## 2 三种分数

外观 app = 候选位姿下每个历史 LiDAR 点投影处的 Query patch token 与该点在参考帧自身成像处的
patch token 的余弦均值（DINOv2 ViT‑B/14，第 11 层 qkv value 面，768 维，560 px 模型边，40×30 patch，
即库里既有特征提取器的配方，不是 RGB 色差）。
可见性 vis = 深度带投票：(+1 查询深度与投影历史深度一致 / −1 不一致) 的均值（容差 1.5 m，
查询帧自身 LiDAR 生成 5×5 近–远深度带）。
几何 geo = 候选自带的截断最近邻均值残差（取负号，越大越好）。

AUC 用各候选自己的投影集计算；逐对胜率用两种位姿的共同支撑（同一批物理点）计算，这是主指标。

| 分数 | 合并 AUC | 帧内 AUC（208 帧均值） | 逐对胜率（主指标） |
|---|---|---|---|
| 外观 app | 0.547 | 0.469 | **0.325**（301/926） |
| 可见性 vis | 0.462 | 0.362 | **0.185**（171/926） |
| 几何基线 geo | 0.442 | 0.390 | **0.323**（299/926） |

合并 AUC 0.547 是帧间分数水平差异造成的假象（同一帧的候选同时偏高或偏低），帧内 AUC 与逐对胜率一致
地低于 0.5。每帧取最高分候选：app 29/208（0.139）、vis 15/208（0.072）、geo 28/208（0.135），
而"随机挑一个候选是正确"的基线是 0.238——三个判据都比随机差。

## 4 最简单判据与按日期留一

排序判据（每帧取最高分候选）本身无参数，逐帧结果见第 2 节。带门限的版本（分数领先第二名超过阈值，
阈值取其余三日的中位领先量，按日期留一）如下：

| 留出日期 | 阈值 | 接受的帧 | 挑对帧 |
|---|---|---|---|
| 2012-02-12 | +0.059 | 17/176 | **0** |
| 2012-02-19 | −0.024 | 23/23 | 13 |
| 2012-03-31 | −0.017 | 4/4 | 0 |
| 2012-05-26 | −0.020 | 5/5 | 2 |

阈值不可迁移：在主日期上它只放行 17 帧且全错。没有任何可选的判据能在跨日期上成立。

## 5 失败归因（625/926 对判错，占 67.5%）

按固定次序先命中者归类：

| 归因 | 对 | 占比 |
|---|---|---|
| 投影覆盖不足（正确候选点 <300 或 patch <30） | 0 | 0% |
| 跨日期外观差异过大（正确候选的 app < 0.25） | 162 | 25.9% |
| 两个候选视野几乎相同（覆盖 patch 的 IoU ≥0.7） | 62 | 9.9% |
| 历史参考视角更贴近"错位"候选（中位距离近 >1 m） | 250 | 40.0% |
| 其他 | 151 | 24.2% |

- 覆盖不是问题：中位 7 万个投影点、610 个 patch。
- 视图重合成度：逐对覆盖 patch 的 IoU 中位数 0.60，只有 10% 的对 ≥0.7。
- 主导机制是"判据度量的是与历史视角的一致性，不是与真值的一致性"：参考帧位置到两个候选的中位距离，
  正确候选 7.8 m、错位候选 6.6 m；56% 的对里错位候选更靠近参考视角。分数差与"谁更靠近参考"的相关系数
  app 0.647、vis 0.435、geo 0.307。参考更贴近正确候选时 app 胜率 0.580，更贴近错位候选时 0.127。
- 参考帧几何本身很偏：02-12 的参考距查询真值中位 10.6 m、航向差中位 121.6°（32 帧是反向行驶）；
  02-19 为 4.1 m / 73.3°；05-26 为 2.4 m / 11.8°。胜率随这个距离单调变好（0.18 → 0.87 → 0.94）。
- 正对照（把查询帧自己当历史，24 帧/98 对，同时同地即零跨日期零视角差）：app 胜率 **0.929**、vis **0.714**，
  正确候选 app 0.414 对错位 0.315。说明打分机制本身有效，失效来自历史参考的视角/日期偏移。

## 6 判定

**外观 + 可见性在这个尺度（9 m 平移）上没有区分力，而且在本数据上方向是反的（逐对胜率 0.33 / 0.19，
低于 0.5）；与几何代价相比不更好（0.32），三者都在随机以下。** 唯一成立的子集是参考帧贴近查询真值的日期
（02-19、05-26，参考距 2–4 m），那里逐对胜率 0.87–0.94；这不是可用的判据，而是"参考视角必须已经对准"的
前提条件。同帧自参照的 0.93 说明瓶颈在历史参考，而不在投影、标定或特征。

## 8 自检与偏离

- 恒等自检：把某参考帧自己的点用自身位姿投回自身图像，app = 1.000、vis = 1.000（说明标定、投影、
  patch 绑定、深度带全链路自洽）。
- 相机模型用冻结的 K（808×616 原始像素）与 T_BC（`library.json`），参考相机外参用参考自身的 T_WC；
  T_WC = T_WB·T_BC 在库内逐项核对一致（10⁻³ m 量级）。
- 初版深度判据只用 5×5 最小值滤波，导致正确位姿也有 73% 的点被判"被遮挡"（滤波器天然偏向更近的面）。
  改为近–远带（同一容差 1.5 m）后，恒等自检由 0.64 变成 1.00。这是实现修正，不是调参。
- 未调任何参数；容差 1.5 m、参考数 5、patch 网格 40×30、模型边 560 全部按既有冻结常量取。
- 未崩溃。唯一一次报错是分析脚本读缺字段（`KeyError: 'mask'`，14 个候选零投影导致字段缺失），已改为缺省处理。
