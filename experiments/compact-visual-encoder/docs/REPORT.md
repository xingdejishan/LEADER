# 定位任务驱动的紧凑视觉编码器（NCLT 2502 帧）

用 RGB 图像直接生成 64×64×64 的紧凑特征，替代 SAM ViT-L 的 64×64×256 稠密特征，
下游冻结的 V7 与 MoE 完全不变。训练信号来自 SAM 的关系蒸馏和冻结 V7 的位姿响应。

## 结论

1. **链路已打通，但没有超过无监督基线。** 在同一 2502 帧评估池上，紧凑编码器的达标帧
   （≤1 m 且 ≤2°）是 1410，低于 64 维主成分基线的 1464，也低于 SAM 原特征的 1482。
2. **位置误差与基线持平，退化集中在旋转和普通帧。** 平均位置误差 1.3253 m，与基线
   1.3204 m 的差在置信区间内跨零；平均旋转误差 2.1354° 对 1.9875°，差值的 95% 区间
   是 [0.105, 0.181]，是实打实的退化。
3. **INT8 存储几乎零代价。** 同一编码器 FP16 与逐通道 INT8 的差别只有 0.0002 m 和
   0.0039°，和之前在 SAM 特征上做的量化结论一致。
4. **训练预算仍在起作用，但没有关掉差距。** 600 步时达标 1390，4000 步时 1410，
   而 PCA-64 是 1464。

## 方法

学生网络：MobileNetV3-Small 主干，取 16 倍下采样层做轻量 FPN 融合，输出 64 通道的码，
再由一个 1×1 卷积适配回 256 通道喂给冻结的 V7。存储的是 64 通道的码，每帧
64×64×64 个 INT8，合计 256 KiB，是 SAM FP16 缓存（2 MiB）的八分之一。

预处理与 SAM 严格对齐，否则网格错位：长边缩放到 1024、用 SAM 的像素均值与标准差归一化、
右下零填充到 1024 见方、patch 16 得到 64×64 令牌。这样学生特征和教师特征逐 token 对齐。

两个监督信号：

- **关系蒸馏**：对有效令牌（去掉补边行）随机采样子集，比对两个特征集的余弦相似度结构，
  只要求"谁和谁像"一致，不要求逐元素数值相同。
- **位姿响应蒸馏**：每帧构造 11 个候选位姿（真值、真实初值、三档扰动的各三个），
  分别用教师特征与学生特征计算冻结 V7 的外观能量，要求学生复现教师的能量数值和排序。
  这一项直接对应"特征能否让 V7 区分对错位姿"。

**为什么不是端到端反传：** V7 的精修器内部是闭式加权最小二乘加约束二次规划，实测输出
不带梯度（`refine` 返回的位姿 `requires_grad` 为 False，替代特征的梯度也拿不到），
所以位姿损失无法穿过它回传。改成能量层面的蒸馏后，训练只需要前向。

训练数据是四个训练日期（2012-01-22、2012-02-02、2012-02-18、2012-05-11），与评估的
四个日期完全不重叠；每个日期采样 4000 帧。

## 评估协议

2502 帧评估池：1502 帧困难池加 1000 帧普通池，覆盖四个测试日期。三种变体共享同一点云、
同一初值和同一图像，只改变送进 V7 的 256 维特征。真值只在独立的评分进程读取，
推理进程不接触。评估只到 V7 前端，不包含 MoE 路由与视觉候选仲裁。

## 解读

**瓶颈不在 64 维本身。** PCA-64 用同样 64 个维度、同样 INT8 存储，保住了 1464 帧，
只比原特征少 18 帧；紧凑编码器少了 72 帧。也就是说，"通道压到 64"这件事本身代价很小，
代价来自"从图像重新学一个编码器"，而且是在只有几千帧、单一数据集的训练预算下学。

**退化形态是旋转。** 位置误差在置信区间内没有差别，旋转误差显著变差，普通帧尤其明显
（0.1414 m → 0.1537 m）。这与"特征描述子的判别力被抹平"一致：位置靠几何和外观场的
粗结构就能拉回来，旋转要靠更细的外观梯度。

**一个不太显眼但稳定的发现：极端失败帧上紧凑特征的旋转误差反而更低**
（8 帧十米以上失败帧，旋转 64.65° 对 70.98°）。这些帧的位姿本来就没有意义，
不宜作为优点宣传，但它说明学生的特征不是简单地"更糊"，而是改变了优化落点。

**训练预算的证据。** 600 步时达标 1390，扩到 4000 步并加大任务项权重后是 1410，
方向正确但没有收敛到 PCA 的水平，也没有出现性能回退，说明继续加预算还有空间。

## 局限

- 单次训练，没有做超参搜索，没有多种子；编码器只在 NCLT 上训练，Oxford 未验证。
- 评估只到 V7 前端，没有把结果接入 MoE 路由与视觉候选仲裁。
- 与 PCA 的比较不完全对等：PCA 解的是闭式最优线性基，学生还要同时学编码器和适配器，
  在同等训练预算下更难。
- 位置误差的比较受极端帧拖累，均值不是最稳的指标，表中同时给出了中位数与达标帧数。

## 下一步

优先级最高的是**先证明学习式 64 维有上限收益**：冻结 SAM 特征，只训一个 256→64 的
线性瓶颈，损失用同一套位姿响应，和 PCA-64 直接对照。这一步不需要图像编码器，
训练成本低一个量级，能干净地回答"任务驱动选维度是否比方差选维度更好"。
只有它成立，再投入编码器替换才有依据。

其次是把关系蒸馏从"全局相似度结构"改成"局部邻域结构"（每个令牌只和最近邻比），
以及两阶段训练（先纯蒸馏收敛，再用位姿响应微调）。
