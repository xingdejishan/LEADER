# 残余不确定性引导的子空间优化：成立条件与验证协议

本文件补齐三件事：全集跨日期的各向异性统计（含协议）、把“全局无别名”写进成立条件、以及用留出日期打破循环的验证方案。已测与待测严格分开。

## 1. 框架

V7 输出记为 T0，几何代价记为 E_g(T)。位姿修正量 ξ 的 MAP 估计：

    ξ* = argmin_ξ [ E_g(T0 · exp(ξ̂)) + ½ ξᵀ Σ⁻¹ ξ ]

Σ 是 V7 在不同自由度上的残余误差协方差。第二项不是装饰：无约束优化会让已经可靠的分量去换几何代价，而几何代价下降并不等于真实误差下降（见 §4 的 yaw 消融）。

低维近似：只保留沿轨 s 与小范围横向 l，

    T(s, l) = (R_V7, t_V7 + s·e∥ + l·e⊥),   |l| ≤ 0.5 m,  旋转不优化

二次代理：在可信区间内 E_g(s) ≈ a s² + b s + c，取 s* = −b / (2a)。**必须带三条有效性检查**：a > 0；顶点落在采样区间内；该区间的残差未贴到截断上限。任一不满足则退回网格。截断代价的二次性只在未饱和区间成立，这是量出来的，不是假设。

## 2. 成立条件（缺一不可）

理论只在下述两条同时成立时有效：

- **C1 残差条件**：主要残余误差落在被优化的子空间内（沿轨方向）。
- **C2 可辨识条件**：在该子空间内，地图代价既**局部可辨识**（沿轨曲率显著大于零），又**全局无别名**（沿轨上不存在另一个代价同样低的竞争位置，即模糊度比 ρ 高于阈值）。

C2 的两半必须分开写。局部曲率大只说明“在小范围里能分辨”，不排除几百米外有个更像的地方。三帧 444 米正是 C1 成立、C2 全局那一半不成立：局部曲率存在，但错误地点代价更低（0.65 对 0.79），此时受限优化不但无效，还会把错误位姿改得更“像”。

因此 router 不是另一个模块，而是 **C2 的执行器**：ρ 低于阈值就判定“这一维不可信”，不再做子空间优化，改由独立来源的假设竞争。理论与路由是同一条件的正面与反面。

## 3. 打破循环的验证协议

风险：若用“一维搜索效果最好”来论证“残差是一维的”，是循环论证。

协议：**按日期留一，估计与评估分离。**

1. 在日期集合 A 上，从 V7 位姿与真值的误差向量分解出主方向，得到 Σ_A（各向异性结构），据此固定子空间（例如只保留沿轨、横向限幅 0.5 m）。
2. 在**未参与估计**的日期集合 B 上，用 A 定的子空间做优化，报告增益。
3. 轮换 A/B 四次，报告每折的结果与总体。

理论成立需要两个预测都兑现：

- **方向稳定性**：A 上估出的主方向在 B 上仍是主方向（用 B 的误差分解核对，不看优化结果）。
- **增益可迁移**：在 B 上用 A 的子空间优化，增益与在 A 上相当；且比“B 上事后选出的最优子空间”差不了多少。

如果只有第二个成立而第一个不成立，说明子空间是事后拟合的，理论不成立。

## 5. 表述红线

- 只说“现有实验支持该解释的若干环节”，不说“证明了普遍成立”。
- 二次代理只称“局部近似”，不称最优性保证。
- 新颖性主张限定为一句：**优化子空间由学习式定位器精修后的残余误差结构决定，而不是由地图的几何退化结构决定。** 前者是配准领域的常规做法（退化方向不优化），后者换了一个信息来源；这一句要成立，依赖 §3 的跨日期稳定性。
