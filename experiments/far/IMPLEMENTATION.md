# LEADER + FAR

从官方纯 LiDAR LEADER L0 出发；冻结 RPGE、MMRegressor 和 SAM，不初始化或加载 MaGiC、CMR、射线束模块。原 SC2-PCR 和对应池的 1.2/0.6 m Tukey/SVD 精修保留。

唯一新增机制是绝对地图坐标上的正向外观配准：观测描述子与地图外观场在初始位姿附近做三维相关，由概率偏移的均值/协方差求共享刚体修正，将修正作用到全部场景坐标预测，再调用原后端。方案来源是用户指定 FAR 文档，当前已完成第1–10轮开发集评价，见 RESULTS.md；40轮尚未完成，不是独立测试。

Cam5 原始 LiDAR 点先按 0.2 m 体素去重，再按原图像素做最近深度 z-buffer，最多保留 2048 个。冻结 SAM-L 特征按缓存缩放和 1024 padded canvas 双线性采样；原 RGB 经 stride-4 三层 CNN（16/32/32 通道），按对应特征像素中心采样。两层 288→64→32 MLP 输出单位观测描述子。

外观场为 12 层三线性哈希编码，每层 2^17 个二通道条目，等比网格间距 25.6 m 到 0.1 m，24→64→32 MLP 后归一化。不输入观测角度，也不保存点云或参考图像。坐标是所有帧共享的地图坐标减官方固定 center_t，而非每帧减质心。空间哈希支持范围外查询，不根据评价集真值设置地图范围。

两轮各用 5×5×5 模板，间距 0.4/0.1 m；温度初值 2、范围 0.03–10，三维偏移标准差初值 0.02 m、范围 0.005–0.1 m，均可训练。通过概率均值与完整三维协方差构建 [-skew(y-c), I] 雅可比，双精度 6×6 解算，一次初始解后两次 Huber-IRLS（马氏阈值 2.5）。旋转用 SO(3) 指数映射，绕传感器位置旋转并加平移。每轮为局部线性求解，不能将它描述成整个非线性目标的全局闭式最优解。

训练以 GT 位姿叠加传感器中心处随机刚体扰动：三轴旋转标准差 1.2°，平移 0.15 m；15% 样本乘 2.5 以覆盖尾部，先验精度为上述主体分布协方差的逆。两轮相关使用标准差为模板间距一半的高斯软标签，真实偏移在模板立方体外的点不参与该轮相关监督。损失为两轮相关交叉熵均值，加全扫描点定位误差的 Huber 均值（delta=0.2 m）。第二轮监督目标不反传，第二轮实际位置及相关仍允许向第一轮传播梯度。

seed20、40 轮、Adam 1e-3、逐帧累积 4 帧，每轮 1200 训练帧/300 更新。只训练 RGB CNN、描述子、哈希表、场 MLP、温度和偏移标准差。每轮对既有四日期 1200 帧产生无 GT 预测，再由单独 CPU evaluator 读取隔离真值，按原归一化综合指标及两个单项选 best；这是选模集合成绩，independent_test=false。没有添加实验矩阵。

每 64 个观测点做一次 125 候选查询，反向重算哈希场激活以控制显存。保存完整最新模型/Adam/NumPy/采样器/Torch/CUDA 状态及每轮模型权重、预测冻结与评价哈希。源码、数据、SAM、官方权重都纳入绑定；不把检查权重用于正式训练。

CPU 检查覆盖连续坐标/哈希梯度、刚体修正方向与无位移返回、两轮可微优化。真实帧检查覆盖四训练日期、两次完整累积更新、所有新增部分梯度和移除 GT 的开发帧推理，以及全部预测坐标变换后原后端的刚体等变性。运行情况另见 RUN_STATUS.md。
