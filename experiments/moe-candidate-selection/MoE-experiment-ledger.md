# MOE 改善实验台账

**用途**：在提出任何"改善 MOE"的新方案之前，先在这里对一遍。每条都记了做法、结论、
关键数字和依据来源。目的是避免重复踩已经踩过的坑——本圆桌上一次提"参考数从三张加到
二十四张"时就犯了没查台账的错，而 v11 早就量过地图规模的影响。

**维护**：新实验无论正负都追加一行；被推翻的结论不要删，标注"已推翻"和推翻它的实验。

---

## 1. 固定口径

| 项 | 值 |
|---|---|
| 评测集 | 1502 困难帧（四天）；普通 1000 帧单独算 |
| 评分器 | 冻结统一评分器，真值含 255 帧替代策略 |
| 部署基线 | refined_V7：MPE 1.9130 / MOE 2.5234 / 进一米两度 621 |
| 普通集基线 | MPE 0.1391 / MOE 1.0862 |
| LEADER 本体 | MPE 2.1899 / MOE 3.3110（V7 是它的精修） |

**关键提醒**：MOE 与 MPE 的账要分开算。沿轨搜索只动平移，对 MOE 零贡献；旋转移植只动
旋转，对 MPE 零贡献。混在一起讨论会得出错误结论。

## 2. 误差结构（事实，不是方法）

| 编号 | 结论 | 数字 |
|---|---|---|
| S1 | 旋转误差三分之二在偏航 | V7：roll 1.05°(25.6%)、pitch 1.12°(6.9%)、yaw 1.47°(67.5%)；LEADER 偏航占 80.3% |
| S2 | 单轴反事实（上界，非可实现） | 去 yaw −0.83°；去 roll+pitch −1.05°；去 roll −0.41°；去 pitch −0.49° |
| S3 | 误差集中在尾部 | 困难集 >2° 691 帧(46%, 载 74.8% 误差)、>5° 57 帧(3.8%, 26.1%)、>10° 17 帧 |
| S4 | 普通集没有尾部 | >2° 仅 2.9%，>5° **零帧**，中位 1.06° |
| S5 | 中位旋转在所有配置下不动 | V7 1.836 / 搜索 1.836 / 偏航扫描 1.856 / 移植 1.808 / 混合 1.834 |
| S6 | 地板 ≈ 地图自身不一致 + 估计器 | 参考地图自身一致性：\|offset\| 均值 0.56°、p90 2.0°、83% 在 1° 内（8 张参考建图） |
| S7 | 经验式：ΔMOE = 替换比例 × 平均超出量 | 153/1502 × (5.66−2.03) = 0.370，实测 2.5234→2.1531 即 0.3703 |
| S8 | 精修是收缩算子，缺"不动"这个选项 | 对它动手的每一帧：1000 帧（67%）变好、均改善 1.53°；502 帧（33%）变坏、均恶化 0.69°。逐帧取优的 oracle 是 2.2945，即恒等捷径的上界 **0.229°** |

**由此得到的判据**：任何"更准的估计器"要有效，逐帧精度须优于 ~1.5°，且覆盖面要广；
只改选取规则最多再挣 0.02°（见 M13）。

## 3. 被否掉的假设

| 编号 | 假设 | 做法 | 结论与数字 |
|---|---|---|---|
| H1 | 地板是共同旋转偏置（标定/坐标系错） | 逐帧误差的世界系均值再扣掉 | **否**。均值 [0.48,−0.54,0.05]°，标准差 [1.97,3.14,6.01]°；扣掉后 2.5235→2.4363，样本外 2.5064→2.4152；普通集偏移≈0.01°——标定误差不会在两集差三十倍 |
| H2 | 每个录制日期的外参不同 | 按日期各拟合一个偏移 | 样本内 2.5235→2.3168，但 12 个参数、不可部署；且四日期均值符号混乱 |
| H3 | 误差随航向/场景密度变化 | 相关分析 | **否**。航向 r=0.013，局部参考密度 r=0.001 |
| H4 | 误差随速度增长 | 相关 + 四分位分档 | 部分否。r=0.315，但分档中位 1.25/2.02/1.98/1.89——只有最慢一档更好，非单调 |
| H5 | 地板来自扫描运动畸变 | 与车自身转向速率相关 | **否**。r=+0.049；四分位中位 1.09/1.91/2.08/2.52，中间不单调 |
| H6 | 偏航不可达是因为平移错 | 在真值平移 vs 在管线输出平移各扫 ±15° | **成立但要限定**。真值平移下 15/16 可辨识；管线自身平移下只有 5/16 可达 |
| H7 | 视觉候选的旋转天然准、平移不准 | 在选中帧上分半量 | **否，且相反**。候选平移好 11 倍（0.69 vs 8.08 m），旋转只好 2.8 倍（2.03 vs 5.66°）；两者改善相关 r=0.78 |
| H8 | 纯视觉质量分可以替代激光验证 | 用内点数/重投影/覆盖选候选 | **否**。三种规则覆盖 904 帧但均值 14.3–14.5°；激光验证 783 帧均值 2.71° |

## 4. 被否掉的方法

| 编号 | 方法 | 结论与数字 |
|---|---|---|
| M1 | 偏航网格扫描（±20°/2° 粗 + ±2°/0.5° 细） | 2.5234→2.4041（−0.12°）。但与视觉替换叠加后只剩 1 帧增量（998）；且是暴力搜索 |
| M2 | 点到面高斯-牛顿，6 自由度 | MOE 2.9528→3.0469（更差），MPE 略好；12 次迭代全用满，未收敛 |
| M3 | 点到面高斯-牛顿，4 自由度（LeGO-LOAM 式） | MOE 2.9528→2.9426（−0.01°），仍不收敛 |
| M4 | 滚转/俯仰网格搜索 | 2.5234→2.5785（**更差**），进一米两度 717→630 |
| M5 | 平面级配准（墙面法向直方图 + 圆相关） | \|offset\| 3.62°，p90 8.75°，仅 17% 在 0.5° 内——比点级差六倍；每帧垂直面点中位仅 700 |
| M6 | 消失点/重力方向（LSD + 最小二乘 VP，拟合坐标系） | 留出集 8.74°，样本内 3.76°——远达不到 1–1.5° 门槛 |
| M7 | 杆状地标 | 修好检测器后中位 4 根/帧、75% 帧 ≥3；但同杆位置重复性 0.88 m、十检九不重复；6 帧可估，偏航 2.31° vs V7 0.87° |
| M8 | 只移植旋转（保留搜索平移） | 被"整份位姿替换"完全支配：MPE 1.9130 vs 1.1601，MOE 相同 |
| M9 | 只移植平移 | MOE 完全不变（2.5234） |
| M10 | 鲁棒旋转平均（IRLS 弦距离 L1，多候选融合） | 783 帧上 2.71→2.59（−5%），中位 2.05→1.98；对端到端 MOE 贡献约 0.01° |
| M11 | LEADER 与其精修的地图代价仲裁 | 只在 84 帧（6%）选 LEADER，MOE 2.5224 vs 2.5235——等于没有 |
| M12 | 精修门控（要不要精修） | 历史已否：收益被下游沿轨纠正吃掉；强行应用 0.9144→1.2126 |
| M13 | 更好的选取规则（换打分/调阈值） | 选取已近 oracle：可部署 2.1065 vs 用真值挑 2.0896，差 0.017° |
| M14 | 旋转监督微调（训练侧） | 训练帧 −13%，独立日期 −0.1%——不泛化 |
| M15 | 增大地图规模（半径 25→12/18 m、体素 0.5/0.8 m） | v11 已测："半径和点云粗化的影响远小于裁剪"，指标几乎不动 |
| M16 | 纯视觉筛选替代激光验证 | 见 H8 |
| M17 | 时序/相邻帧 | 用户约束排除（必须单帧） |
| M18 | 改进参考地图（多参考联合、位姿图收紧） | 用户排除（数据侧不改）；且按 S6，即使做到也只解释地板的三分之一 |
| M19 | 恒等捷径：真值无关的选择器决定保留 LEADER 还是 V7 的旋转 | 上界（用真值二选一）2.5235→2.2945，即 0.229°。留一日期逻辑回归（特征：两姿态地图代价差、旋转差、平移差）准确率 65.5%，MOE 只到 2.5026（−0.021°，吃到上界的 9%）。**结论：上界真实存在，但现有可观测量选不出来** |
| M20 | 候选互证（consensus acceptance，参考集不相交的候选互相印证） | 判别力强：正确候选 m≥2 的比例 38% vs 错误 11%，**AUC 0.811**（对比几何分 0.455）。但端到端无收益。同底座对照（搜索＋偏航扫描，底座 MPE 1.6076/MOE 2.4041）：只用作当前规则 = 0.9706 / 2.1065 / 732；追加 m≥2 采纳 108 帧 → 1.0030 / 2.1083 / 726；追加 m≥3 采纳 67 帧 → 0.9759 / 2.1037 / 731。**结论：信息真实且独立，但转不成指标增益**；死帧上基率 10%、精确率上限 43% |
| M21 | **学习式判据**：15 个现有特征（几何分、与基线分差、帧内秩与 z 分、内点、重投影、残差、支撑方位、互证、验证位、位姿差）→ 梯度提升树，留一日期验证 | **正结果（小）**。AUC 0.939（几何分单项 0.895）——叠加确实强于单特征。端到端同底座：对照（只用余量规则）0.9706 / 2.1065 / 732；**最佳规则（分数过基线 且 GBM 概率≥0.7，否则退回余量规则）→ 0.9613 / 2.0884 / 748**。增益：MOE −0.018、MPE −0.009、进一米两度 +16 帧。加入帧级上下文（歧义比值、基线分、候选数）AUC 无提升（0.938） |
| M22 | **帧级互证门**：max_cons（同帧内被独立参考印证的候选数上限）用来判断"这一帧有没有救"，候选仍按分数挑 | **帧级判别满分**。55 个死帧上：41 个无可用候选的帧 max_cons 全为 0，14 个有可用候选的帧全部 ≥1，**AUC 1.000**；阈值 ≥1.2 时选中 11 帧、11 帧全对。但直接当全局门会崩（cons≥1 时采纳 618 帧，MPE 2.58）——根因是拿候选分去和 V7 分比，而部署底座是搜索位姿 |
| M23 | **把参照换成部署位姿**：用同一代价函数现场给搜索位姿打分，候选与它比（互证门≥1 且候选代价更低） | **正结果（小）**。同底座：对照 0.9706 / 2.1065 / 732 → **0.9628 / 2.0885 / 741**（delta 0）。增益 MOE −0.018、MPE −0.008、命中 +9 帧。与 M21 同一量级，说明两条路吃的是同一份信息 |

## 5. 有效的改动（唯一一组）

| 编号 | 方法 | 数字 |
|---|---|---|
| P1 | **整份位姿替换**：候选几何分超 V7 基线 0.10 以上即替换（153 帧，无需歧义门） | V7 之上：MPE 1.9130→1.1601，MOE 2.5234→2.1531，进一米两度 621→674 |
| P2 | 叠加沿轨搜索后再替换 | MPE 0.9706，MOE 2.1065，进一米两度 732，>10 m 5 帧 |
| P3 | 余量扫描 | 0.05/0.10/0.15 → MPE 1.0406/0.9706/1.2738，0.10 为平台中心 |
| P4 | 旋转移置（若不取整份位姿时的次优） | 2.5234→2.1531，MPE 不动；但被 P1 支配 |

**依赖的性质**（不是"旋转更准"，而是三点交集）：存在第二个信息源在某些帧上明确更好；
有真值无关的分数能认出那些帧；那些帧承载大部分误差。

**边界**：超地板 773 帧里只有 474 帧存在可用第二估计、357 帧真更好。瓶颈已从"挑不准"
变成"没有可挑的"。要再往下走，唯一路径是把视觉支路的通过率从 52% 提上去——而纯视觉
质量分不能替代激光验证（H8），检索也未见跟着位姿错（相关系数 +0.005）。

## 7. 一句话总结

**MOE 不是估计问题，是分布问题**：典型帧的朝向精度被钉在 1.8°（困难集）/1.06°（普通集），
四条独立估计器（V7、激光搜索、偏航扫描、视觉 PnP）都撞在同一处；能改善的只有"主估计器
跌出地板"的那部分质量，而它的收益严格等于"替换比例 × 平均超出量"。任何方案提出之前，
先问它改变的是这两项里的哪一项；都改变不了的，就不必做。
