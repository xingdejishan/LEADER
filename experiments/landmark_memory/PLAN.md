# 多模态参考地标交互：10%持续目标的第一项架构

2026-09-25。最新用户指令覆盖旧138步固定末步停止规则：围绕多模态，使MPE或MOE降低至少10%；每种新架构需充分训练，用验证集选择最佳checkpoint，不展开无决策价值的诊断。

## 目标和决策

暂以LEADER＋SC2-PCR＋两阶段全池(1.2,0.6)为基准：313帧MPE=0.11660947377561828m，MOE=1.1082095915488175°；成功要求MPE≤0.10494852639805645m或MOE≤0.9973886323939358°，另一项不恶化且完整分母无失败。40帧仅选模，313帧仅在架构内选模冻结后评价；反复开发已使两个集合成为开发集，不声明独立泛化。

旧SpatialDecoder只跑过138步，结果否定该预算下的升级，不证明架构收敛后上限。本次选择不同结构依据是：历史视觉在固定LiDAR候选中有消歧证据，已有query-only适配无法稳定实现这个优势；让参考视觉信息在线进入坐标修正，比继续增加普通卷积有更直接的依据。

## 最多三个候选及来源

1. SACReg：参考图像及稀疏已知坐标经cross-attention帮助查询预测场景坐标。迁移“带坐标的参考证据进入预测”原语；保持当前LiDAR初值及强后端，不复刻CroCo或宣称原论文验证此模型。选中。https://arxiv.org/abs/2307.11702
2. 2D3D-MATR：图像/点云粗到细显式匹配，迁移patch间匹配原语；完整像素到点配准会改变后端和数据准备，本轮不选。https://openaccess.thecvf.com/content/ICCV2023/papers/Li_2D3D-MATR_2D-3D_Matching_Transformer_for_Detection-Free_Registration_Between_Images_and_ICCV_2023_paper.pdf
3. NeRF-Loc：连续3D描述子与2D图像匹配；条件场和外观适配具有相关性，但建场成本高于现有稀疏参考库，本轮不选。https://arxiv.org/abs/2304.07979

## 唯一架构增量

参考库仅由552训练扫描构建，保存冻结LEADER描述子、同帧SAM图像描述子、已知地图坐标，以及LEADER在参考点的三维回归误差。查询用LEADER预测坐标从地图半径3m内取最多32候选，每参考帧最多4点；训练排除同帧和同日期10秒内近邻，查询候选绝不使用查询GT。

共享LiDAR/视觉投影分别处理查询与候选，拼接两模态逐通道乘积/差异、候选相对位置、参考误差及可靠度，生成候选交互表示与attention权重；聚合表示与参考误差经零初始化输出层产生三维修正，加到原LEADER坐标。原可靠度、top50%选择及位姿后端不变；无有效图像或候选的点输出结构性零残差，不做按定位结果的模型切换。

该模块改变在线参考输入及值传递，不是旧query-only门控或仅训练时使用参考对比监督。参考GT用于已声明的建图，与查询GT严格隔离。参考点是RPGE中心，其跨视角位置并非同一真实表面点，因此传递的是参考回归误差，不直接把匹配中心当作精确同名点。错误候选仍可能污染修正，3m局部候选不保证可迁移；本实验直接用位姿结果决定是否保留，不另做null/置乱诊断。

已审查历史query-gaussian、anchored-fusion、crossframe-probe及本地/缓存refs，记录audit.json；未确认同一完整在线误差memory架构的完成结果，不宣称基本attention/参考地图原语原创。旧地点先验失败限制了粗地点修正，不能据此认定局部双模态参考匹配必然失败或成功。

## 训练、充分性及选模

冻结LEADER和SAM；缓存仅避免反复编码，查询缓存无GT。训练标签与reference map独立存储。训练所有具备图像支持且进入原top50%的点，SmoothL1(beta=0.1)监督三维坐标修正，不训练置信度、位姿头或更换后端。

AdamW学习率3e-4、weight_decay=1e-4，batch1024，seed37，最少40轮，每5轮运行完整40帧验证并选择checkpoint。验证选模优先两项均不高于基准者，再取min(归一化MPE,归一化MOE)最小；若无合格者则保留两项均值比平均最小者但不得宣布成功。学习率按验证平台下降，连续30轮没有超过0.1%量级的选模改善且至少两次学习率下降后才允许平台停止；初始上限160轮，到上限仍改善则标记未充分并继续扩展，不能把上限写成已收敛。

只有验证最优、最新优化器状态两个大checkpoint长期保留，所有验证预测/评价和每次候选hash保留。不查看313帧挑checkpoint；最终权重及hash冻结后评价一次313帧。失败则明确该具体机制未达标，保留证据并继续有依据的下一架构，不能停止整个10%目标或以参数网格替代设计。

成本：参考库及所有冻结特征一次生成；随后小型网络在缓存上充分训练。必要检查仅GT边界/候选排除、零初始化、图像及参考路径梯度和一次训练到评价联通检查。
