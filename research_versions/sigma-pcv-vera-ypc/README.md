# Σ-PCV（sumPCV）＋VERA＋YPC：代码与简要结果

截至2026-10-03的研究快照。三种方法分别保留代码、核心思路和已实际评价的结果；评价口径不同，不能跨行直接排名。

| 方法／版本 | 核心思路（简写） | 核心指标（简写） | 状态 |
|---|---|---|---|
| Σ-PCV，3＋3轮 | 学每点Σ；椭球125候选＋共享FAR外观场；后验坐标／协方差送后端 | MPE **0.1418m**／MOE **1.4150°**；对照0.1389m／1.4041°；Joint957/1200 | 略退化 |
| VERA，原版e4 | 图像在LiDAR局部表面选择端点，视觉特征与位移进入坐标回归 | MPE **0.2855m**／MOE **1.8202°**；Joint789/1200 | 未胜对照 |
| VERA，support e30 | 以实际raw回波支撑重锚点，继续适配回归头 | MPE **0.2307m**／MOE **1.6883°**；Joint842/1200 | 未胜对照 |
| VERA，FOV追加e10 | 加官方相机FOV／遮挡门禁，继续适配 | MPE **0.2203m**／MOE **1.6760°**；Joint846/1200 | 未胜对照 |
| VERA，repair e1 | 可回退端点选择＋显式地图坐标运输＋独立质量监督／保护入池 | MPE **0.4221m**／MOE **2.1731°**；Joint646/1200 | 首轮更差；用户停止，五轮未完成 |
| YPC，coarse e4 | 整帧共享yaw候选；固定raw回波／图像像素，旋转地图查询；相位CE | 相位RMSE **0.9553°**，零修正0.6415°；Top1 **24.58%**，常数0°29.58% | 相位gate失败；无新的完整位姿MPE／MOE |

MPE＝平均位置误差；MOE＝平均旋转误差；Joint＝位置<1m且旋转<2°。Σ-PCV／VERA为各自1200开发帧；YPC为240训练侧留出帧的一维相位测量。

VERA历史纯LEADER微调对照：**0.1795m／1.6242°，Joint849/1200**。对照与部分VERA版本的主干训练／坐标拼接不同，这些是整系统结果，不能全部归因于视觉模块。

- [VERA](VERA/README.md)：原版、support、FOV、repair源码及对应评价。
- [YPC](YPC/README.md)：相位头、训练／评价入口及失败gate。

源码保持历史字节；配置保留原实验路径和资源约束。运行需要另备NCLT、LEADER／FAR／SAM权重、已有缓存及兼容的MinkowskiEngine／PyTorch环境，并重新绑定本机路径与哈希；本目录不是自动安装或一键启动包。数据、权重、缓存和服务器连接脚本未纳入本次上传。

这些结果均不证明最终独立测试或跨数据集泛化；有限轮数和被中止的训练不写成充分收敛。后续坏点识别／修正网络属于独立延伸实验，不把其点级成功率冒称原Σ-PCV定位指标。
